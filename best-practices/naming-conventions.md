# Naming Conventions

##### Effective 2026-09-16

Best practices for naming files and folders.

## Folders

Folders should have a hyphen between each word and be no more than 2 words.
`folder-name`

## Markdown Files

Markdown files should have a hyphen between each word and be no more than 3 words.
`markdown-file-name.md`

## C/C++ Files

C/C++ files should use snake case and should be one word when possible. C header files should only be one word.
`file.c`
`header.h`

## Python Files

Python files should follow [PEP 8](https://peps.python.org/pep-0008/) guidelines. Files names should use snake case.
