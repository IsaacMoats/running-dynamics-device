# Project Scope

##### Updated 2026-09-17

General project ideas and scope

## Timeline

The finalized version of the project should be produced in it's final form factor at the end of 2027. The first workable iteration should be produced at the end of 2026. The features produced at each milestone are to be determined.

## Cadence

The device should accurately measure cadence (step rate).

## Ground contact time

The device should measure the amount of time each foot is in contact with the gound. The device should also easily present data for how much time the foot spends in the air. This can be calculated by using the cadence and ground contact time, but it may be better if it is measured instead in order to mitigate error if cadence changes drastically mid stride.

## Foot path

The device should be able to reconstruct the foot's flight path in 3D space over time.

## Relative foot distance

The device should measure distance between the feet.
